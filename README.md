# 字字樂 · 香港 K3 認字遊戲

給香港幼稚園高班（K3）細路嘅繁體中文認字遊戲。讀音用廣東話，字形用香港常用繁體字。

教育局冇官方 K3 認字表。呢隻遊戲跟《幼稚園教育課程指引》(2017) 嘅方向：用生活主題同遊戲認讀，唔當默書。

## 點樣玩

```bash
npm install
npm run dev
```

瀏覽器打開顯示嘅網址，用 iPad、電話或者電腦都可以。

- **聽音認字**：聽廣東話，再揀漢字
- **睇圖認字**：睇圖同意思，再揀字
- **認讀卡**：慢慢睇字、聽音、記拼音

課題包括家庭、身體、動物、食物、天地、學校、顏色、數字、動作、出行。

## 備註

- 朗讀用瀏覽器嘅 `zh-HK` 語音（Safari / Chrome 較穩）
- 進度同星星存在本機瀏覽器
- 大人可以喺主頁開關拼音
